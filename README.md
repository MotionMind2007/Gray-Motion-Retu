# Gray Retu - Modern Dining Experience 🍽️

A premium, silver-themed restaurant website featuring a dark mode aesthetic, smooth animations, and dynamic menu loading.

## Features

- **Modern UI/UX**: Silver and Teal color palette with a glassmorphism header.
- **Dynamic Menu**: Loads 20+ food items dynamically from a `products.json` file.
- **Advanced Animations**: 
  - **GSAP & ScrollTrigger**: For interactive hero sections and parallax card effects.
  - **AOS (Animate On Scroll)**: For smooth reveal effects as you scroll.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Clean Structure**: Folders organized for scalability.

## Project Structure

```text
Gray Retu/
├── index.html          # Main landing page
├── css/
│   └── retu.css        # Custom styles with glassmorphism & themes
├── js/
│   └── retu.js         # Fetch logic & GSAP animations
├── assets/
│   └── products.json   # Menu database with 20 items
├── pages/
│   ├── about.html      # Restaurant history
│   ├── contact.html    # Reservation & mapping
│   ├── gallery.html    # High-quality food showcase
│   └── service.html    # Services offered
└── README.md           # Documentation
```

## 🛠️ Built With

- **HTML5 & CSS3** (Custom Properties)
- **JavaScript (ES6+)**
- **GSAP** (GreenSock Animation Platform)
- **AOS** (Animate On Scroll)
- **Google Fonts** (Poppins)
- **Unsplash API** (High-quality stock imagery)

## 📖 How to Use

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. To add or change food items, simply edit `assets/products.json`.
